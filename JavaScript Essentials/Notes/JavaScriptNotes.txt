Timers — setTimeout, setInterval, requestAnimationFrame

Immutability — Object.freeze, immer, immutable patterns

Currying & Partial Application

Memoization & Caching

41–50: Browser, Performance & Security
DOM Manipulation — selection, creation, traversal

Events — bubbling, capturing, delegation, preventDefault, stopPropagation

Browser Storage — localStorage, sessionStorage, cookies, IndexedDB

CORS & HTTP — status codes, headers, preflight

Security — XSS, CSRF, CSP, sanitization

Performance — reflow/repaint, lazy loading, code splitting, tree shaking
