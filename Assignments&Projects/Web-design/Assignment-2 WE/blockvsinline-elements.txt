Block Elements
Start on a new line 

Take up the full width available by default

Can contain other block elements and inline elements

Can have height, width, margins, and padding set

examples: <div>, <p>, <h1> to <h6>, <ul>, <ol>, <li>, <section>, <article>, <nav>, <header>, <footer>, <form>


Inline Elements
Do not start on a new line

Take up only as much width as necessary

Typically cannot contain block elements

Width and height properties have no effect.

Used within text flow for styling or marking up parts of content

examples: <span>, <a>, <strong>, <em>, <img>, <br>, <button>, <input>, <sup>, <sub>, <small>
